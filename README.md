# Edgewood Cabinetry: concept site by LuminArch

A pitch demo for Edgewood Cabinetry (Clayton, NC, serving the Triangle). **Not the official site.** Every page is noindex and carries a concept banner.

- Live (temporary, GitHub Pages): https://daveo820.github.io/edgewood-cabinetry-demo/
- Stack: hand written static HTML, CSS and JS, generated by `build.py` (whe-fest pattern from the LuminArch style guide).
- Files: `css/design-system.css` (tokens), `css/components.css`, `css/pages.css`, `js/main.js`, `img/` (client photos as WebP), `DESIGN_DNA.md`, `FACTS_LOG.md`, `market-research.md`, `research/`, `screenshots/`.

## Edit and preview
```
python3 build.py
python3 -m http.server 8000
```
The estimate form is a demo and sends nothing.
